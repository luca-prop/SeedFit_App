# MVP-028 기본 접근성 점검 260627

## 목적

MVP-028은 SeedFit MVP 핵심 B2C 흐름에서 기본 접근성 문제가 배포 전 검수를 막지 않도록 점검하고 보강하는 작업이다.

이번 범위는 WCAG 전체 준수 선언이 아니라, MVP 사용자가 키보드와 보조기기에서 핵심 입력·선택·이동을 이해할 수 있게 만드는 기본 안전장치다.

## 범위

- 입력창 label
- 버튼 aria
- 키보드 이동
- 색상 대비 및 선택 상태

## 구현 내용

### Landing

- 예산 범위 슬라이더에 설명 문구를 연결했다.
- 빠른 예산 선택 버튼에 `aria-pressed`와 구체적인 accessible name을 추가했다.
- 현재 선택된 빠른 예산 범위가 시각적으로도 드러나도록 선택 스타일을 추가했다.
- 검색 CTA에 현재 예산 범위가 포함된 accessible name을 추가했다.
- 결과 프리뷰 카드 버튼에 선택 상태와 구역/행정구/단계/초기투자금 정보를 포함한 accessible name을 추가했다.

### Results

- 정렬 select에 스크린리더용 label을 추가했다.
- 자치구 필터와 사업 단계 필터를 각각 `role="group"`으로 묶고 그룹명을 제공했다.
- 필터 칩 버튼에 `aria-pressed`와 선택/해제 상태를 포함한 accessible name을 추가했다.
- 차트에 스크린리더용 설명 문구를 연결했다.
- 차트는 보조 설명을 제공하되, 같은 구역 상세/비교 이동은 아래 카드 목록에서도 이용할 수 있음을 명시했다.

### Comparison

- LTV 모델 선택 영역에 그룹명을 추가했다.
- `생애최초 70%`, `일반 40%` 링크에 대출 가정 목적이 드러나는 accessible name을 추가했다.
- 현재 선택된 LTV 모델에 `aria-current="page"`를 추가했다.

## 검증 결과

- `npm run build`: 통과.
- IDE lints: 수정 파일 기준 오류 없음.
- 브라우저 접근성 snapshot:
  - Landing 빠른 예산 버튼이 pressed/released 상태로 노출됨.
  - Results 정렬 combobox가 `결과 정렬 기준` 이름으로 노출됨.
  - Results 필터 칩이 선택/해제 상태와 구역 수를 포함해 노출됨.
  - Results 차트 설명이 접근성 트리에 노출됨.
  - Comparison LTV 토글이 대출 가정 이름과 current 상태로 노출됨.

## 완료 기준

- 핵심 B2C 화면에서 주요 입력과 선택 UI의 accessible name이 존재한다.
- 버튼/토글 선택 상태가 보조기기와 시각 UI 양쪽에 전달된다.
- 키보드로 이동 가능한 CTA와 필터가 의미 있는 이름을 가진다.
- 빌드가 통과한다.

## 제외 범위

- WCAG 전체 준수 선언은 MVP-030 릴리즈 판단 이후 별도 접근성 QA로 다룬다.
- 모바일 보조기기별 스크린리더 실기 테스트는 MVP-028 범위가 아니다.
- 자동 접근성 테스트 도구 도입은 후속 테스트/NFR 작업으로 분리한다.
