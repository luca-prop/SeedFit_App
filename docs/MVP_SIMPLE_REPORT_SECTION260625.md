# SeedFit MVP Comparison Summary 260625

## 1. 목적

이 문서는 `MVP-022: 간단 리포트 섹션 구현`의 의사결정과 최종 구현 기준을 정리합니다.

MVP-022의 목적은 비교 화면에서 사용자가 같은 실투자금 기준의 핵심 판단을 빠르게 이해할 수 있게 하는 것입니다.

검토 결과, 별도의 `간단 리포트` 4칸 섹션은 기존 `비교 요약`과 정보 효용이 겹칩니다. 따라서 별도 섹션을 만들지 않고, `비교 요약` 카드 안에 핵심 숫자와 데이터 한계를 흡수합니다.

구역 상세 Lite의 `특징 및 확인 포인트`와 역할을 분리합니다.

- `특징 및 확인 포인트`: 구역 자체의 정적 큐레이션 설명입니다. 행정구, 사업 단계, 운영팀 메모, 실투자금 범위를 빠르게 확인합니다.
- `간단 리포트`: 비교 페이지의 동적 해석입니다. 선택 LTV 시나리오와 같은 실투자금 기축 대조군 매칭 결과를 바탕으로 예산 적합성, 리스크, 가격 위치, 데이터 한계를 설명합니다.

따라서 비교 화면에는 `비교 요약`만 유지하고, 화면 최상단의 주어는 항상 구역명으로 둡니다.

## 2. 최종 표시 항목

`비교 요약` 카드는 문장형 리포트가 아니라 나열형 핵심값으로 구성합니다.

- 구역 실투자금
- 가장 가까운 기축 후보 필요 현금
- 구역 최소 실투자금 대비 여유/부족
- 기축 대조군 대출 가정
- MVP 데이터 한계와 실제 대출/세금/매물 확인 필요 고지

## 3. 구현 파일

- `frontend/app/app/comparison/[id]/page.tsx`

## 4. 문장 생성 기준

### 가장 가까운 기축 후보

구역 최소 실투자금과 가장 가까운 `Comparison Assets` 후보의 필요 실투자금을 비교합니다. 소액 부족 후보는 `0.1억 부족`처럼 표시하고, 여유가 있으면 `0.5억 여유`처럼 표시합니다.

### 구역 실투자금과 기축 대조군 대출 가정

현재 구역 실투자금 범위와 선택된 기축 대조군 대출 가정을 함께 표시합니다.

주의: 재개발 구역 실투자금에 LTV를 적용한다는 의미가 아닙니다. LTV는 `Comparison Assets`의 기축 필요 현금을 계산하는 가정입니다.

### 데이터 한계

비교 요약에는 MVP 데이터 한계 문장을 고정 포함합니다.

```text
이 비교는 MVP 큐레이션 데이터와 기축 대조군 LTV 가정으로 만든 참고 정보이며,
실제 대출 승인액·세금·매물 상태는 별도 확인이 필요합니다.
```

## 5. 제외한 내용

사업 단계 리스크 문장은 비교 페이지에서 제외합니다.

사업 단계 리스크는 구역 자체의 해석에 가깝기 때문에 `구역 상세 > 특징 및 확인 포인트` 또는 후속 심층 리포트에서 다루는 것이 더 적합합니다.
