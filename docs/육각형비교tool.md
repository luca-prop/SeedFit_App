1. [12시] 급지 (Location Tier) 산출 체계
지도의 소수점 급지 인덱스(Index, 1.0 ~ 4.2)를 기반으로 10점 만점 기준 점수로 직결 산출한다. (가감점 보정 규칙은 기준 단순화를 위해 생략함)

1.1 산출 공식 (10점 만점)
Score12 = (급지표 100점) / 10

1.0~1.5는 100점(10.0). Index 1.6부터는 Index 0.1마다 100점에서 1점씩 내린다.

100점 = 100 − max(0, Index − 1.5) × 10

예: 성수 1.6 = 99점 = 9.9, 일원 1.9 = 96점 = 9.6, 마곡 3.0 = 85점 = 8.5, 갈현 4.0 = 75점 = 7.5.

2. 영역별 상세 평가 산출 로직 (10점 만점 체계)
2시·4시 플래그는 검수 보드에서 구역마다 확인한다. 급지 가점과 세대수는 자동이다.

2.1 [2시] 희소성·상품성
Score2 = min(10.0, 6.0 + 조망 + 급지 + 고급화)

1) 조망
한강은 영구 > 부분 > 벨트 중 한 칸. 공원은 메이저 > 일반·하천 중 한 칸.
한강 영구와 공원뷰가 같이 있어도 한강 영구 +2만 넣는다. 부분·벨트는 공원뷰와 더할 수 있다.
- 한강 영구 조망 +2
- 한강 부분 조망 +1
- 한강벨트 지역 +0.5
- 메이저 공원뷰(서울숲, 올림픽공원, 용산공원 등) +0.5
- 일반 공원뷰, 하천뷰 +0.3

시공사·고급화 가점은 세대수로 나누지 않는다. 체급은 4시에만 넣는다.

2) 급지 (자동, Index 1.0~2.1 = 2.1 이상)
- 1.0 ~ 2.1 +1.0
- 2.2 ~ 2.7 +0.5
- 2.8 +0.2
- 2.9 이상 0

3) 시공사 및 고급화 특화 — 하나, 최대 +1.5
- 하이엔드 전용 브랜드 확정 +1.5. 아크로, 디에이치, 르엘, 써밋, 오티에르, 드파인. 하이엔드 특화설계는 여기에 포함. 래미안·자이는 단지에 따라 하이엔드로 볼 수 있다.
- 1군 브랜드 + 고급 특화설계 +0.8. 래미안, 자이, 롯데캐슬, 푸르지오, e편한세상, 아이파크, 더샵, 힐스테이트, SK뷰 등인데, 아래 중 2개 이상을 전면 적용한 경우. 예: 롯데캐슬 이스트폴, 청량리 L65.
  - 외관: 커튼월룩, 스카이브릿지, 해외 설계사 협업 외관
  - 커뮤니티: 스카이라운지, 단지 내 수영장, 조식 서비스 식당, 게스트하우스
  - 내부·설비: 음식물 자동 이송, 천장고 2.45m 이상, 층간소음 차단재 250mm 이상
- 1군 메이저 시공사 일반 표준 +0.4. 파격 특화 없이 표준형. 예: 미아 2구역, 전농 8구역, 제기 4구역.
- 2·3군 또는 시공사 미정 +0

2.2 [4시] 규모·생활편의
Score4 = min(10.0, min(6.5, 세대수 + 뉴타운) + 교통합 + 생활합 + 학군 + 초품아)

1) 세대수 (자동)
5,000세대 이상 6.5 / 3,000 6.0 / 2,000 5.5 / 1,000 5.3 / 500 5.0 / 300 4.0 / 1~299 3.0

2) 뉴타운·신도시급 +1.0. 세대수와 합쳐 6.5를 넘지 못한다.

3) 교통 — 해당분 모두 합산
- 역세권 +1
- 중심위치, 더블 역세권 +0.3
- 한강벨트 교통 +0.5
- GTX역 접근 +0.3

4) 대형상권·생활편의 — 해당분 모두 합산
- 대형 공원/강/하천 +0.3
- 대형 쇼핑몰(백화점, 스타필드) 인접 +0.3
- 종합병원 인접 +0.2

5) 학군 — 둘 중 하나
- 대치·목동·중계 +1
- 범대치·범목동·범중계, 광장, 명일, 우장산, 수내, 정자, 평촌, 반포, 방배, 잠실 등 +0.5

6) 초품아 +0.3

2.3 [6시] 필요 투자금 (Required Capital / Investment Barrier)
다른 축과 같이 0~10점이다. 높을수록 진입 장벽이 크다. 최소 실투자금(억)을 현재 데이터 전체 분포에 묶어 점수로 환산한다.

기준은 육각형 데이터를 다시 만들 때 한 번 계산한다. 매물 한 건이 바뀌었다고 화면을 열 때마다 바꾸지 않는다.

- 0점 = 현재 데이터에서 가장 낮은 최소 실투자금
- 5점 = 중간값
- 7.5점 = 상위 25% 경계
- 10점 = 가장 높은 최소 실투자금
- 사이 구간은 직선으로 잇는다.

2026-10-24 데이터(107곳): 0점=1.55억, 5점=6.5억, 7.5점=10억, 10점=30억(성수전략4구역). 10억은 7.5점, 성수전략1(21억)은 8.9점.

def generate_hexafit_v2_chart(data_list, output_path="hexafit_v2_chart.png"):
