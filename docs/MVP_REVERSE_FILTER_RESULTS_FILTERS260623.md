# SeedFit MVP Reverse Filter Results Filters 260623

## 1. 목적

이 문서는 `MVP-016: 결과 정렬 및 필터 UI 구현`의 결과를 정리합니다.

MVP-016의 완료 기준은 사용자가 Reverse Filter 결과를 리스트만 보지 않고, 스캐터 차트에서 사업 단계와 필요 현금 분포를 먼저 이해한 뒤 후보 구역을 좁힐 수 있게 하는 것입니다.

## 2. 사용자 결정

- 필터 상태는 URL 쿼리에 저장합니다.
- 검색 결과 페이지 상단에 스캐터 차트를 바로 표시합니다.
- 행정구와 진행 단계는 드롭다운이 아니라 결과 개수가 붙은 칩 버튼으로 켜고 끕니다.
- X축은 `Phase2_scatter_chart검토.md` 기준의 재개발 8단계로 표시합니다.
- 필터 범위는 행정구 칩, 단계 그룹 칩, 정렬입니다.
- 기본 정렬은 `budgetFit asc`입니다.
- **coverage 기본은 CORE만** (정비구역지정 이후). SUB는 `includeSub=1` 또는 「초기 구역(SUB) 포함」 토글로 켭니다.
- `예산 초과` 구역은 사용자 기본 화면에서 제외합니다.
- 스캐터 차트 점을 누르면 구역 툴팁을 고정하고, 차트 배경을 누르면 선택을 해제합니다.
- 라벨은 전부 숨기지 않고 대표 라벨을 선별 표시합니다.
- `전체`, `전체 단계` 칩은 다시 누르면 전체 해제 상태가 됩니다.
- 스캐터 툴팁과 하단 구역 리스트에는 `같은 예산으로 살 수 있는 기축단지 비교` CTA를 제공합니다.

## 3. URL Query Contract

결과 페이지는 다음 쿼리를 읽습니다.

```text
/app/results?budgetMin=100000000&budgetMax=300000000&districts=용산구,성동구&stageGroups=추진준비,구역지정&sort=budgetFitAsc&includeSub=1
```

- `budgetMin`: 최소 가용 현금 KRW
- `budgetMax`: 최대 가용 현금 KRW
- `districts`: 선택 행정구 CSV. 없으면 전체. `__none`이면 전체 해제
- `stageGroups`: 선택 사업 단계 CSV. 없으면 전체. `__none`이면 전체 해제
- `sort`: 정렬 옵션. 없으면 `budgetFitAsc`
- `includeSub`: `1`/`true`/`yes`이면 SUB(구역지정 전) 포함. **없으면 CORE만**

URL에 필터 상태를 남기는 이유는 새로고침, 공유 링크, Vercel Preview 리뷰에서 같은 결과를 재현하기 위해서입니다.

기존 `district`, `stage` 단일 쿼리는 이전 구현과의 호환을 위해 읽을 수 있지만, MVP-016 이후 기본 링크는 `districts`, `stageGroups`를 사용합니다.

## 4. 표시 정책

MVP-015에서는 개발 검증을 위해 `예산 초과` 그룹까지 화면에 표시했습니다.

MVP-016부터는 B2C 사용자 경험을 기준으로 기본 결과에서 `예산 초과` 구역을 숨깁니다. 사용자는 "내 예산으로 가능한 후보"와 "조금 조정하면 가능한 후보"를 찾고 있으므로, 기본 화면은 다음 두 그룹에 집중합니다.

- 예산 내 진입 가능
- 예산 근접

`예산 초과` 데이터는 Server Action 결과에는 남아 있지만 화면 기본 섹션과 스캐터 차트로 렌더링하지 않습니다. 추후 필요하면 "예산을 늘리면 볼 수 있는 후보" 같은 별도 UX로 재도입합니다.

## 5. X축 8단계

원천 사업 단계 문자열은 `Phase2_scatter_chart검토.md` 기준으로 다음 8단계에 매핑합니다.

- `추진준비`: 연번부여, 대상지 선정, 신속통합기획, 관리계획수립 등
- `구역지정`: 구역지정, 관리계획고시, 추진위 승인 등
- `조합설립`: 조합설립인가, 사업시행자 지정 등
- `시공사`: 시공사 선정, 건축심의 등
- `사업시행`: 사업시행인가
- `관리처분`: 관리처분인가
- `이주철거`: 이주, 철거
- `착공`: 착공

색상은 진행이 완료될수록 긍정적이라는 사용자 인지를 반영해 4개 계열로 묶습니다.

- 빨간색: 준비
- 노란색: 지정·조합
- 초록색: 시공사·사시
- 파란색: 관처·이주·착공

## 6. 라벨 표시 정책

모든 구역 라벨을 항상 표시하면 1~3억 예산처럼 특정 단계에 구역이 몰릴 때 차트가 읽히지 않습니다. 반대로 모든 라벨을 숨기면 AHA 모먼트가 약해집니다.

따라서 MVP-016은 다음 정책을 사용합니다.

- 필터 후 결과가 8개 이하이면 모든 라벨을 표시합니다.
- 9개 이상이면 대표 라벨을 최대 6개만 표시합니다.
- 같은 X축 단계에서는 대표 라벨을 최대 2개만 표시합니다.
- 대표 라벨은 예산 내 후보, 높은 적합도, 작은 예산 차이를 우선합니다.
- 사용자가 클릭한 구역은 항상 라벨을 표시하고 강조합니다.
- 라벨은 `청파3`, `신정1`처럼 축약명으로 표시합니다.

## 7. 툴팁과 하단 리스트 정책

스캐터 차트 툴팁은 큰 분류를 먼저 이해할 수 있도록 `X축 단계 → 사업 단계 → 필요 현금` 순서로 표시합니다. 점을 클릭하면 같은 정보가 차트 안에 고정되며, 고정 상태에서 `같은 예산 기축단지 비교` CTA로 이동할 수 있습니다.

MVP-016 시점에는 LTV/취득세가 실제 금액에 반영되지 않아 `실투자금 범위`와 `필요 현금 범위`가 동일합니다. 중복 노출을 줄이기 위해 하단 리스트는 카드형 상세 화면 대신 2~3줄짜리 컴팩트 행으로 표시합니다.

하단 리스트는 스캐터 차트에서 라벨이 생략된 구역을 훑어보는 보조 장치입니다. 정보는 툴팁과 중복되므로 `구역명`, `필요 현금`, `X축 단계`, `세부 사업 단계`, `예산 적합도`, `같은 예산 기축단지 비교` CTA만 표시합니다.

## 8. 정렬 옵션

- `budgetFitAsc`: 예산 적합도 높은 순
- `investmentMinAsc`: 최소 실투자금 낮은 순
- `investmentMaxAsc`: 최대 실투자금 낮은 순
- `zoneNameAsc`: 구역명 가나다순
